# 🤖 AI Agent Guide - Smart Cleanup Assistant

## Overview

The AI Agent is your smart assistant that understands natural language commands. Just tell it what you want to do, and it will handle the rest - safely!

## 🛡️ Automatic Protection

**Your important files are automatically protected:**
- ✅ **Portfolio folders** - Automatically detected and protected
- ✅ **OneDrive** - Automatically detected and protected
- ✅ **Custom paths** - Add any path you want to protect

**Protected files are NEVER deleted, even if you ask the AI to delete everything!**

## 💬 How to Use

### 1. Open AI Agent Panel
- The AI Agent panel is on the left side of the main window
- Or use the welcome screen to access it

### 2. Type Your Command
Just type what you want in natural language:

```
delete all safe files
find large files
protect my portfolio
remove all node_modules
clean temp files older than 30 days
```

### 3. Press Enter or Click Send
The AI will understand your command and execute it safely!

## 📝 Command Examples

### DELETE/REMOVE Commands

**Delete all safe files:**
```
delete all safe files
remove everything safe
clean all safe files
```

**Delete specific categories:**
```
delete all node_modules
remove all temp files
clean all logs
remove python environments
```

**Delete by size:**
```
delete files larger than 500MB
remove files bigger than 1GB
clean files over 100MB
```

**Delete by age:**
```
delete files older than 30 days
remove files older than 90 days
clean old files from last year
```

**Delete duplicates:**
```
remove duplicates
delete duplicate files
find and remove duplicates
```

### FIND/SEARCH Commands

**Find large files:**
```
find large files
show files bigger than 100MB
list huge files
```

**Find old files:**
```
find files older than 90 days
show old files
list files from last year
```

**Find duplicates:**
```
find duplicates

```

### PROTECT Commands

**Protect a path:**
```
protect C:\Users\...\Portfolio
never delete OneDrive
exclude my projects folder
protect "C:\My Important Files"
```

**The AI will:**
- Add the path to protected list
- Never delete files in that location
- Show confirmation message

### INFO Commands

## 🛡️ Protected Paths Management

### View Protected Paths
- Check the "🛡️ Protected Paths" panel
- See all currently protected locations

### Add Protected Path
1. Click "➕ Add Path" button
2. Select a folder to protect
3. That folder and all subfolders are now protected

### Search & Protect
1. Click "🔍 Search & Protect" button
2. Type a search term (e.g., "portfolio", "onedrive")
3. Select matching folders from results
4. Click "🛡️ Protect Selected"
5. Those folders are now protected forever!

### Remove Protection
1. Select a path in the protected list
2. Click "➖ Remove" button
3. Confirm removal

## 🧠 How It Works

The AI Agent uses natural language processing to:
1. **Understand intent** - What do you want to do?
2. **Extract parameters** - Size, age, category, path
3. **Execute safely** - Respects all safety rules
4. **Protect important files** - Never touches protected paths

## ⚠️ Safety Features

**Multiple layers of protection:**
1. ✅ System files are never deleted
2. ✅ Protected paths are never deleted
3. ✅ Confirmation required for deletions
4. ✅ Files go to Recycle Bin (recoverable)
5. ✅ AI checks safety before every action

## 💡 Tips

1. **Be specific** - "delete all node_modules" is better than "delete stuff"
2. **Use numbers** - "files larger than 500MB" works great
3. **Protect first** - Protect important folders before scanning
4. **Check stats** - Use "show stats" to see what you're working with
5. **Start small** - Try "find large files" before "delete all"
